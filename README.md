# Birthday Party Proposal

A static, mobile-first comedic funding proposal built with Vite, React, Tailwind CSS, Framer Motion, canvas-confetti, and qrcode.react.

## Personalise it

Edit [src/config.js](src/config.js) to set the recipient and sender names, party date, requested amount, UPI ID, and WhatsApp number. This is the one place intended for personal details.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

Push this repository to GitHub, import it into Vercel, and select the **Vite** framework preset. No environment variables are required. Vercel's default `vite build` command publishes `dist`.
